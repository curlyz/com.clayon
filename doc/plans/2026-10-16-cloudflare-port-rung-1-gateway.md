# Paperclip Cloudflare Port — Rung 1: Gateway Recipe Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Prove the antl one-stack recipe inside com.paperclip: a Hono + oRPC gateway Worker, OpenAPI-first contract, Kysely over Postgres, one real read slice (`agents`), proven locally on `wrangler dev` with zero changes to the legacy Express server.

**Architecture:** New sibling packages only — `packages/contract` (hand-authored `openapi.yaml` as the first artifact; oRPC contract + zod generated from it, committed, never hand-edited) and `gateway/` (Hono Worker with one oRPC router, two doors: `/api/rpc/*` and `/api/<spec path>`, plus `/api/openapi.json` serving the bundled spec byte-equal). Local Postgres in Docker through a local-only Hyperdrive config; repository class with constructor injection wired per request. Nothing deploys in this rung; deploy, PlanetScale, and domain decisions are rung 2.

**Tech Stack:** Hono 4.13.13, @orpc/* 2.0.0-beta.43, @hey-api/openapi-ts 0.0.0-next-20260930190945, @redocly/cli 2.63.0, zod 4.6.7, kysely ^0.28.7 + pg ^8.16.3, wrangler 4.150.0, typescript 7.0.2, oxlint + oxfmt. All pinned exactly as proven in `com.vintageui` and recipe `moe:orpc/recipe-openapi-first-heygen` (2026-10-15).

**Spec:** This plan is the spec for rung 1 (brainstorming happened in session, 2026-10-16: port map table, split verdict — control plane to Workers, executors stay containers). Law: `antl:convention/stack.md`, `moe:orpc/recipe-openapi-first-heygen`, `antl:convention/backend-data` rule 0 (repository classes, constructor injection).

| rung | what | status |
|---|---|---|

## Global Constraints

- **OpenAPI-first, non-negotiable** (operator 2026-10-15): `packages/contract/openapi.yaml` is authored BEFORE any router code; generated output is committed and never hand-edited; `bun run check:openapi` gate fails on drift. Recipe: `moe:orpc/recipe-openapi-first-heygen`.
- **Versions pinned exactly**: `@orpc/server,contract,openapi,json-schema,zod` `2.0.0-beta.43`; `@hey-api/openapi-ts` `0.0.0-next-20260930190945`; `@redocly/cli` `2.63.0`; `zod` `4.6.7` (identical in contract AND gateway — one zod across the generated-schema consumer chain, recipe gotcha); `hono` `4.13.13`; `wrangler` `4.150.0`; `typescript` `7.0.2`; `kysely` `^0.28.7`; `pg` `^8.16.3`.
- **No type guards, no `as`, no `any`** (operator 2026-10-10/15): parse unknown data with zod `safeParse`; failures are results or `ORPCError`. No anonymous inline object type literals in signatures; every object shape is a named type beside its owner.
- **Dependency injection** (operator 2026-10-15): repository interface + concrete class, constructor-injected, wired per request in `index.ts`; no module-singleton grabs, no DI container.
- **No barrel files**; no `index.ts` re-exports.
- **API is path-based**: every route under `/api/...` on the worker; no subdomain API.
- **Tests: none for this surface** (paperclip `AGENTS.md` keeps vitest for the legacy tree; this rung proves via lint + `tsc --noEmit` + `wrangler dev` live curls + `wrangler deploy --dry-run`, per `antl:convention/stack.md` tests row).
- **Legacy untouched**: no edits under `server/`, `ui/`, `cli/`, `packages/db/`, `packages/shared/`, no changes to Bun `overrides` or `patchedDependencies`. The only legacy-file edits are one `workspaces` entry in root `package.json` (add `gateway`) and one script line in the same file.
- **No worktrees, no branch switches** (shared checkout law). Commits with `git claude`, scoped to `com.paperclip` paths, from the antl root.
- Ports: gateway dev `8810`, local Postgres `5497` (vintageui uses 8801/5494; heygen recipe 8820 — no clashes).
  - **Pivot (2026-10-16, later the same day):** local Postgres moved from docker `5497` to Homebrew `postgresql@18` on `127.0.0.1:5433` (docker daemon was unresponsive); see `gateway/package.json`, `gateway/scripts/seed.ts`, `gateway/wrangler.jsonc`. openapi: 3.1.0
info:
  title: Paperclip gateway
  version: 0.1.0
  description: >-
    The Paperclip control-plane API. Rung 1 carries the liveness door and the
    read-only agent roster of one company; later rungs add auth, more slices
    and the runner protocol. Every response carries Cache-Control no-store and
    x-request-id.
servers:
  - url: http://127.0.0.1:8810/api
paths:
  /health:
    get:
      operationId: health
      summary: Liveness of the gateway
      description: Answers 200 with the service name and a generatedAt stamp.
      responses:
        "200":
          description: The gateway is up
          content:
            application/json:
              schema:
                $ref: "#/components/schemas/Health"
  /agents:
    get:
      operationId: listAgents
      summary: The agent roster of one company
      description: >-
        Agents of the given company, newest first, at most the limit. The
        read model is the stable roster subset of the agents table; no
        config or secret field ever reaches the wire.
      parameters:
        - name: companyId
          in: query
          required: true
          description: The company whose agents are listed.
          schema:
            type: string
            format: uuid
        - name: limit
          in: query
          required: false
          description: Maximum agents returned, 1 to 100, default 20.
          schema:
            type: integer
            minimum: 1
            maximum: 100
            default: 20
      responses:
        "200":
          description: The agent roster, newest first
          content:
            application/json:
              schema:
                $ref: "#/components/schemas/AgentList"
  /agents/{agentId}:
    get:
      operationId: readAgent
      summary: One agent of the roster
      description: >-
        The roster subset of one agent by id. An unknown id answers 404.
      parameters:
        - name: agentId
          in: path
          required: true
          description: The agent id.
          schema:
            type: string
            format: uuid
      responses:
        "200":
          description: The agent
          content:
            application/json:
              schema:
                $ref: "#/components/schemas/AgentEnvelope"
        "404":
          description: No agent with that id
components:
  schemas:

      type: object
      required: [data, meta]
      properties:
        data:
          $ref: "#/components/schemas/HealthData"
        meta:
          $ref: "#/components/schemas/GeneratedMeta"
      additionalProperties: false
    HealthData:
      type: object
      required: [status, service]
      properties:

          description: Always ok when this response is served.

          type: string
          description: The service name, paperclip-api.
      additionalProperties: false

- [x] **Step 6: Create `src/agentsRepository.ts`**

One interface and one concrete Postgres repository own the agents queries (`antl:convention/backend-data` rule 0). Request-scoped instance built in `index.ts`; a transaction would take its own injected handle.

```ts
import type { Selectable } from "kysely";

import type { DatabaseShape, GatewayDatabase } from "./database";

// The roster subset the contract's Agent schema promises. Field-for-field
// the wire shape of packages/contract openapi.yaml Agent — no config, no
// secret, no lifecycle detail beyond the state string.
export type AgentView = Selectable<DatabaseShape["agents"]>;

export type ReadAgentsParams = {
  companyId: string;
  limit: number;
};

export interface AgentsRepository {
  readAgents(params: ReadAgentsParams): Promise<AgentView[]>;
  readAgent(agentId: string): Promise<AgentView | null>;
};

export class PostgresAgentsRepository implements AgentsRepository {
  private readonly database: GatewayDatabase;

  constructor(database: GatewayDatabase) {
    this.database = database;
  }

  async readAgents(params: ReadAgentsParams): Promise<AgentView[]> {
    return this.database
      .selectFrom("agents")
      .selectAll()
      .where("agents.companyId", "=", params.companyId)
      .orderBy("agents.createdAt", "desc")
      .limit(params.limit)
      .execute();
  }

  async readAgent(agentId: string): Promise<AgentView | null> {
    const rows = await this.database
      .selectFrom("agents")
      .selectAll()
      .where("agents.id", "=", agentId)
      .limit(1)
      .execute();
    return rows[0] ?? null;
  }
}
```

import { readFileSync, readdirSync } from "node:fs";
import { join } from "node:path";

import { Pool } from "pg";
import { z } from "zod";

// Applies every pending migration in migrations/ inside one transaction
// each, tracked by name in schema_migrations. A later deploy rung runs the
// same script against the real connection string (DATABASE_URL, never
// committed).
const DEFAULT_URL = "postgres://paperclip:paperclip@127.0.0.1:5497/paperclip";
const connectionString = process.env.DATABASE_URL ?? DEFAULT_URL;
const dir = join(import.meta.dirname, "..", "migrations");

const pool = new Pool({ connectionString, max: 1 });
await pool.query(
  "CREATE TABLE IF NOT EXISTS schema_migrations (name TEXT PRIMARY KEY, applied_at TIMESTAMPTZ NOT NULL DEFAULT now())",
);
const appliedRows = z
  .array(z.object({ name: z.string() }))
  .parse((await pool.query("SELECT name FROM schema_migrations")).rows);
const applied = new Set(appliedRows.map((row) => row.name));

for (const file of readdirSync(dir)
  .filter((name) => name.endsWith(".sql"))
  .sort()) {
  if (applied.has(file)) continue;
  const sql = readFileSync(join(dir, file), "utf8");
  const client = await pool.connect();
  try {
    await client.query("BEGIN");
    await client.query(sql);
    await client.query("INSERT INTO schema_migrations (name) VALUES ($1)", [file]);
    await client.query("COMMIT");
    process.stdout.write(`applied ${file}\n`);
  } catch (error) {
    await client.query("ROLLBACK");
    throw error;
  } finally {
    client.release();
  }
}
await pool.end();

import { contract } from "@clayon/contract";

import type { AgentsRepository } from "./agentsRepository";

/*
 * The whole rung-1 API surface: procedures implementing the GENERATED
 * contract (packages/contract/openapi.yaml is the source of truth, recipe
 * moe:orpc/recipe-openapi-first-heygen). Procedures receive the
 * request-scoped AgentsRepository; wiring (src/index.ts) owns its database
 * and lifetime. Rung 1 is read-only: nothing to announce to an invalidator.
 */

export type GatewayContext = {
  env: PaperclipGatewayEnv;
  agents: AgentsRepository;
};

const os = implement(contract).$context<GatewayContext>();

const generatedMeta = () => ({ generatedAt: new Date().toISOString() });

const health = os.health.handler(() => ({
  data: { status: "ok", service: "paperclip-api" },
  meta: generatedMeta(),
}));

const listAgents = os.listAgents.handler(async ({ input, context }) => ({
  data: await context.agents.readAgents({
    companyId: input.query.companyId,
    limit: input.query.limit ?? 20,
  }),
  meta: generatedMeta(),
}));

const readAgent = os.readAgent.handler(async ({ input, context }) => {
  const agent = await context.agents.readAgent(input.params.agentId);
  if (agent === null) throw new ORPCError("NOT_FOUND", { message: "No such agent." });
  return { data: agent, meta: generatedMeta() };
});

```ts
import { SmartCoercionHandlerPlugin } from "@orpc/json-schema";
import { OpenAPIHandler } from "@orpc/openapi/fetch";
import { onError } from "@orpc/server";
import { RPCHandler } from "@orpc/server/fetch";
import { ZodToJsonSchemaConverter } from "@orpc/zod";
import { Hono } from "hono";

import spec from "@clayon/contract/spec.json";
import { PostgresAgentsRepository, type AgentsRepository } from "./agentsRepository";
import { createGatewayDatabase } from "./database";
import { router } from "./router";

/*
 * The rung-1 public surface of the Paperclip gateway on the OpenAPI-first
 * recipe (moe:orpc/recipe-openapi-first-heygen): packages/contract/openapi.yaml
 * is the source of truth, the contract is generated from it, and this Worker
 * serves every path through one router with two doors:
 *   /api/<spec path>    the REST door (oRPC OpenAPIHandler)
 *   /api/rpc/<opId>     the oRPC RPC door for typed clients
 *   /api/openapi.json   the checked-in spec, bundled verbatim by redocly
 *
 * Every /api response, errors included, is no-store and carries x-request-id
 * (echoed when sent).
 */

type GatewayHonoEnv = {
  Bindings: PaperclipGatewayEnv;
  Variables: { agents: AgentsRepository };
};

const app = new Hono<GatewayHonoEnv>();

const rpc = new RPCHandler(router, {
  interceptors: [onError((error) => console.error(error))],
});
const rest = new OpenAPIHandler(router, {
  interceptors: [onError((error) => console.error(error))],
  plugins: [new SmartCoercionHandlerPlugin({ converters: [new ZodToJsonSchemaConverter()] })],
});

type GatewayContextSource = {
  env: PaperclipGatewayEnv;
  executionCtx: { waitUntil: (work: Promise<unknown>) => void };
  get: (key: "agents") => AgentsRepository;
  req: { raw: Request };
};

const gatewayContext = (c: GatewayContextSource) => ({
  env: c.env,
  agents: c.get("agents"),
});

// One database per request (the curly gateway scope shape): the pool is
// lazy, queries open it; it is destroyed after the response via waitUntil.
app.use("/api/*", async (c, next) => {
  const database = createGatewayDatabase(c.env.HYPERDRIVE.connectionString);
  c.set("agents", new PostgresAgentsRepository(database));
  await next();
  c.executionCtx.waitUntil(database.destroy().catch(() => undefined));
  const headers = new Headers(c.res.headers);
  headers.set("Cache-Control", "no-store");
  if (!headers.has("x-request-id")) {
    const echoed = c.req.header("x-request-id");
    headers.set(
      "x-request-id",
      echoed !== undefined && echoed !== "" ? echoed : crypto.randomUUID(),
    );
  }
  c.res = new Response(c.res.body, { status: c.res.status, headers });
});

// The RPC door (typed oRPC clients).
app.use("/api/rpc/*", async (c, next) => {
  const { matched, response } = await rpc.handle(c.req.raw, {
    prefix: "/api/rpc",
    context: gatewayContext(c),
  });
  if (matched) return c.newResponse(response.body, response);
  await next();
});

// The REST door: the spec's own paths under /api (path-based API law).
app.use("/api/*", async (c, next) => {
  const { matched, response } = await rest.handle(c.req.raw, {
    prefix: "/api",
    context: gatewayContext(c),
  });
  if (matched) return c.newResponse(response.body, response);
  await next();
});

// The served document IS the checked-in source of truth (packages/contract/
// openapi.yaml -> redocly bundle -> spec.json). `bun run check:openapi` fails
// when this file drifts from the spec.
app.get("/api/openapi.json", (c) => c.json(spec));

export default app;
```
